# marloon-dev-site

Portfólio de **Marlon Nunes Vieira**, desenvolvedor de software, com destaque para o
[VM Guave](https://github.com/marloon-dev/vm-guave).

**Site:** https://marloon-dev.github.io/marloon-dev-site/

Feito com React, TypeScript e Vite. A cada push na `main`, o GitHub Actions gera o site e
publica no GitHub Pages.

```sh
npm install
npm run dev      # desenvolvimento
npm run build    # gera dist/
```
